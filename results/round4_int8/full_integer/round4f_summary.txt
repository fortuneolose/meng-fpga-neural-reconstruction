Conclusion
----------
The complete reconstruction algorithm has been demonstrated using
quantised weights and activations, integer convolution accumulation,
integer biases, integer requantisation and an integer bilinear/final
residual path.

The full-integer reference retains essentially all FP32 reconstruction
quality and outperforms bicubic on all 20 held-out validation images.

The current Python convolution emulator uses float64 internally as a
container for exactly representable integer products and sums. A pure
integer golden reference will therefore be produced before HLS/RTL
implementation.
