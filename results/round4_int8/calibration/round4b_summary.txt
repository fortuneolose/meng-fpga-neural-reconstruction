Round 4C initial quantisation policy
------------------------------------
bilinear branch input:
UINT8, scale = 1.0 / 255

conv1 ReLU:
UINT8, max-range calibration

conv2 ReLU:
UINT8, max-range calibration

residual:
signed INT8, symmetric max-range calibration

biases:
FP32

bilinear skip path:
FP32

final residual addition:
FP32

final output:
FP32 followed by existing [0,1] evaluation clamp

Reasoning
---------
The first W8A8 experiment deliberately uses maximum calibration
ranges so that activation clipping is avoided for values observed
during training-set calibration.

Percentile clipping will be considered separately only after the
unclipped W8A8 baseline has been measured.

ReLU activations use UINT8 because their observed values are
non-negative. The residual uses signed INT8 because it contains
both positive and negative values.
